## Features

- Supporting students by using it

  
## How to run it? 

 ### Download the .iso file

```bash
  git clone https://github.com/projectmanges/manges_os/releases
```

### Write the .iso file

```You can use Rufus or Balena Etcher like tools for this section.```


### Boot from the flash drive 

```Look up your bios key for your device or your motherboard. Next, close your computer entirely and insert the flash drive. Then, boot your computer and spam the bios key. Follow the instructions on the screen. ```

## Bilgisayarınızda Çalıştırın

### .iso dosyasını indir

```bash
  git clone https://github.com/projectmanges/manges_os/releases
```

### .iso dosyasını yazdırın.


```Bu bölüm için Rufus veya Balena Etcher gibi programları kullanabilirsiniz.```

### Flash bellek üzerinden önyükleyin

```Cihazınız modeline veya anakart modelinize bakarak bios tuşunun hangisi olduğunu öğrenin. Sonrasında bilgisayarınızı tamamen kapatın. Flash belleği takın. Bilgisayarı Flash bellek takılı iken başlatın ve bios tuşuna sürekli basın (durmadan). Ekrandaki yönergeleri takip edin.```
